# Offchain implementation for Githoney with TX3

For more information about tx3, please refer to the [TX3 documentation](https://docs.txpipe.io/tx3).

## Environment Variables

Ensure you have a `.env` file in the `githoney/tx3-offchain` directory with the following variables:

```js
CREATION_FEE = ...
REWARD_FEE = ...
GITHONEY_ADDRESS = ...
SETTINGS_TX_HASH = <the_tx_hash_of_the_deployed_settings_script>
```

Where `CREATION_FEE` must be a number greater than 2,000,000 (MIN ADA), representing the fee in lovelaces to create a bounty. And `REWARD_FEE` must be a number between 0 and 10,000, representing the percentage of the reward that will be paid.

## Running Tests

To run the tests, add additional variables to the `.env` file:

```js
BLOCKFROST_URL = "https://cardano-preprod.blockfrost.io/api/v0"
BLOCKFROST_PROJECT_ID = preprodMySecretBlockFrostProjectId
MAINTAINER_SEED = ...
CONTRIBUTOR_SEED = ...
GITHONEY_SEED = ...
ADMIN_SEED = ...
SPONSOR_SEED = ...
MAINTAINER_ADDRESS = ...
ADMIN_ADDRESS = ...
SPONSOR_ADDRESS = ...
FT_ADDRESS = ...
CONTRIBUTOR_ADDRESS = ...
```

Where the `preprodMySecretBlockFrostProjectId` can be generated by following this [tutorial](https://blockfrost.dev/docs/overview/getting-started).

Run all tests together using the following command:

```sh
npm run test
```

### Running Individual Tests

```sh
npm run <test-name>
```

Replace `<test-name>` with one of the following options:

- test-create
- test-add-rewards
- test-assign
- test-merge
- test-close
- test-claim
- test-update-settings
- test-close-settings

To execute a comprehensive trace of all operations, run:

```sh
npm run test-demo
```
